# Guía para editar el sitio

Esta guía es para Manuel Tironi y su equipo. **No necesitas saber programar ni usar Git.**

## Acceder al panel de edición

1. Ve a **Editar contenido** en el pie de página del sitio, o abre directamente:
   - Producción: `https://ecologiasdeljabali.cl/keystatic`
   - Desarrollo: `http://localhost:4321/keystatic`

2. Inicia sesión con tu cuenta de **GitHub**.
   - Si no tienes cuenta, el administrador del sitio puede crear una invitación.
   - Solo necesitas iniciar sesión una vez por dispositivo.

3. Verás un panel con secciones en español e inglés.

## Qué puedes editar

| Sección en el panel | Qué es |
|---|---|
| **Cuaderno de campo (español)** | Entradas del blog / bitácora en español |
| **Field notes (English)** | Mismas entradas en inglés |
| **Equipo (español)** | Perfiles del equipo en español |
| **Team (English)** | Perfiles en inglés |
| **Publicaciones** | Lista bibliográfica |
| **Portada** | Título, frase principal y párrafo introductorio |
| **El proyecto / Contacto** | Páginas institucionales |

## Crear una entrada del cuaderno de campo

1. Abre **Cuaderno de campo (español)** → **Create entry**
2. Completa:
   - **Título** y **URL (slug)**: el slug define la dirección web (ej. `primera-salida-terreno`)
   - **Resumen breve**: aparece en listados
   - **Fecha de publicación**
   - **Clave de traducción**: usa el mismo texto en la versión en inglés para enlazar ambos idiomas (ej. `primera-salida-terreno`)
   - **Contenido**: texto con formato (negrita, listas, citas)
3. Estado: elige **Publicado** cuando esté listo
4. Guarda

## Agregar un miembro del equipo

1. **Equipo (español)** → **Create entry**
2. Nombre, rol, afiliación, grupo (investigador o colaborador)
3. Biografía en el editor de contenido
4. Repite en **Team (English)** con la misma clave de traducción

## Agregar una publicación

1. **Publicaciones (español)** → **Create entry**
2. Título, autores, revista/editorial, año, tipo
3. DOI o enlace opcional

## Bilingüismo

- El sitio tiene versión en español (principal) e inglés (`/en/`)
- Cada contenido tiene una **clave de traducción** que enlaza ambas versiones
- Si falta la traducción al inglés, el sitio muestra la versión en español con un aviso

## Imágenes

En esta versión inicial el contenido es principalmente texto. Para agregar imágenes a una entrada, contacta al desarrollador o pide una sesión de capacitación ampliada.

## ¿Algo salió mal?

Contacta al desarrollador del sitio. Todos los cambios quedan guardados en el historial y se pueden recuperar.
